# Lady Wolfpack HQ - Shared AI Instructions

## Project Goal
Maintain and improve the Lady Wolfpack HQ website without breaking existing functionality.

## General Rules
- Preserve existing features unless specifically asked to change or remove them.
- Do not delete working code just to simplify the project.
- Keep the site mobile-friendly.
- Prefer small, focused changes over large rewrites.
- Before making a major structural change, explain why it is needed.
- Do not change team branding, logos, roster data, or colors unless specifically requested.
- Use the existing official Hartford Junior Lady Wolfpack branding already included in the project.
- Keep code readable and organized.

## Collaboration Rules
- ChatGPT and Claude may work on this project at the same time.
- Each AI should work on a different task whenever possible.
- Check ROADMAP.md before beginning work.
- Update ROADMAP.md when a task is completed or materially changed.
- Do not overwrite another AI's unfinished work.
- Commit changes with a clear description of what was changed.

## Safety
- Do not expose passwords, API keys, tokens, or private information.
- Do not remove stored game or roster data unless specifically instructed.
- Avoid changes that could break the live hosted site.
